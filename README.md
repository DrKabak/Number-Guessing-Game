# Number Guessing Game 

An interactive, browser-based number guessing game designed to test fundamental JavaScript logic. This project demonstrates random number generation, dynamic DOM updates, and basic game loop mechanics (like tracking remaining attempts).

## Live Demo
You can play the game live here: https://drkabak.github.io/Number-Guessing-Game/

## Features
* **Randomized Logic:** Generates a new random target number between 1 and 100 for every session.
* **Input Validation:** Captures user guesses and provides real-time feedback through the DOM.
* **State Management:** Tracks and displays previous guesses along with the user's remaining attempts.
* **Custom UI:** Features a dark-themed, centralized interface built with custom CSS.

## Tech Stack
* **Frontend:** HTML5, CSS3
* **Logic:** Vanilla JavaScript
